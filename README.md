# Jordy Peña — Portfolio

My personal portfolio site, live at **[jordypena.com](https://jordypena.com)**.

I'm a software engineer with 5+ years of experience building production web apps. This site gives a quick intro, the stack I work with, a few featured projects, my resume and a way to get in touch.

## Built with

- [React 18](https://react.dev/) bootstrapped with Create React App
- [React Router](https://reactrouter.com/) for page routing
- [react-icons](https://react-icons.github.io/react-icons/) for the stack and nav icons
- Plain CSS per component, with `IntersectionObserver` scroll animations
- [Formspree](https://formspree.io/) to handle the contact form

## Pages

| Route       | What's there                                    |
| ----------- | ----------------------------------------------- |
| `/`         | Landing page                                    |
| `/home`     | Intro, tech stack and featured projects         |
| `/projects` | Project cards with descriptions and live links  |
| `/contact`  | Contact form plus GitHub, LinkedIn and email    |

## Featured projects

- **[Rider Concrete](https://www.riderconcreteandexcavation.com/)**: SEO-focused business site built with Next.js
- **[Pokemon TCG Guru](https://tcg.vercel.app/)**: Look up card values and current and past pricing
- **[Straub Construction](https://construction-freelance.vercel.app/)**: Portfolio and pricing site for a construction business, with pinch-and-zoom blueprints
